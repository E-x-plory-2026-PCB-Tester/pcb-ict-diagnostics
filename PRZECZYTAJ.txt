---------------------------------------------------------
  NAJPROSTSZY SPOSÓB — KLIKNIJ AKTYWATOR
---------------------------------------------------------

W folderze jest gotowy aktywator. Nie musisz nic wpisywać
w konsoli ani znać żadnych komend.

  URUCHOM_WINDOWS.bat    <- Windows      (kliknij dwa razy)
  URUCHOM.sh             <- macOS / Linux

Kliknij go dwa razy. On sam zrobi wszystko po kolei:

  1. znajdzie Pythona na komputerze,
  2. sprawdzi, czy są potrzebne biblioteki — jeśli nie ma,
     doinstaluje je sam,
  3. sprawdzi, czy w folderze leżą potrzebne pliki,
  4. uruchomi program.

Pierwsze uruchomienie może potrwać około minuty, bo instaluje
biblioteki. Każde następne — kilka sekund.

Jeśli aktywator pokaże błąd, napisze dokładnie, czego brakuje.
Wtedy przejdź do sekcji "JEŚLI COŚ NIE DZIAŁA" na dole.

---------------------------------------------------------
  JAK TESTOWAĆ (TRYB DEMO, BEZ SPRZĘTU)
---------------------------------------------------------

Wszystkie główne przyciski są na GÓRNYM PASKU:

1. Kliknij [★ Zapisz wzorzec]
   -> zapisuje bazę ze sprawnej płytki do pliku wzorzec.json
   -> gdyby w folderze był stary wzorzec bez nowych elementów
      (np. bez U1), kliknij ten przycisk raz, aby go odświeżyć

2. Kliknij [▶ Testuj płytkę]
   -> wynik pojawia się w tabeli i na zdjęciu płytki (PASS)

3. Na górnym pasku zmień [SYMULACJA] np. na "odwrocona_dioda"
   albo "zwarcie" i znów kliknij [▶ Testuj płytkę]
   -> celownik na wadliwym elemencie, powód błędu,
      pasek historii (#1, #2, #3...)

4. Dodatkowe funkcje w oknie:
   - kółko myszy na płytce = zoom, przeciągnięcie = przesuwanie
   - pionowy suwak między panelami = szerokość tabeli
   - [A− / A+] = wielkość tekstu w tabeli, [⛶ Pełny] = tabela na cały ekran
   - [⚙ Piny] = konfigurator pinów (klikasz na zdjęcie i zapisujesz mapę)
   - [⚙ Kalibruj] = tarowanie oporu kabli
     (na żywo: zdejmij płytkę, zewrzyj dwie igły przewodem)
   - [SERIAL MONITOR] na dole = podgląd surowego USB (JSON) i wysyłanie komend


---------------------------------------------------------
  PODŁĄCZENIE PRAWDZIWEGO TESTERA (ESP32)
---------------------------------------------------------

Na górnym pasku zmień [ŹRÓDŁO] z "DEMO (Symulator)"
na port COM testera (jeśli podpiąłeś kabel po starcie, kliknij [↻]).

Tester powinien przyjmować komendę "SCAN\n" (115200 baud) i zwracać JSON:

  {"board_id": "test", "scan_ms": 850,
   "readings": [{"a": 0, "b": 1, "mv": 472}, ...]}


---------------------------------------------------------
  JEŚLI WOLISZ RĘCZNIE (albo dwuklik nie działa)
---------------------------------------------------------

Aktywator to tylko skrót — wpisuje te same komendy za Ciebie.
Otwórz konsolę:

  Windows:  Win + R, wpisz cmd, Enter
  macOS:    Terminal
  Linux:    Terminal

WINDOWS:

    cd %USERPROFILE%\Downloads\TesterPlytek
    pip install -r requirements.txt
    python testuj_plytke.py

  Jeśli "python" nie jest rozpoznawane:  py testuj_plytke.py

macOS:

    cd ~/Downloads/TesterPlytek
    pip3 install -r requirements.txt
    python3 testuj_plytke.py

LINUX (Fedora / Ubuntu / Debian):

    # Fedora:  sudo dnf install python3-tkinter python3-pillow-tk
    # Ubuntu:  sudo apt install python3-tk python3-pil.imagetk
    cd ~/Downloads/TesterPlytek
    pip3 install -r requirements.txt
    python3 testuj_plytke.py


---------------------------------------------------------
  JEŚLI COŚ NIE DZIAŁA
---------------------------------------------------------

Aktywator nic nie robi po dwukliku (Windows)
      -> kliknij prawym -> "Uruchom jako administrator"
      -> albo otwórz Wiersz polecenia i wpisz:
         URUCHOM_WINDOWS.bat

"ModuleNotFoundError: customtkinter"
      -> wpisz: pip install -r requirements.txt
         (na macOS/Linux: pip3 install -r requirements.txt)

"python nie jest rozpoznawane"
      -> wpisz  py testuj_plytke.py   (Windows)
      -> albo  python3 testuj_plytke.py  (macOS/Linux)
      -> albo zainstaluj Pythona z python.org, zaznaczając
         "Add Python to PATH" podczas instalacji

Błąd "No module named ImageTk" na Linuksie
      -> Fedora: sudo dnf install python3-tkinter python3-pillow-tk
      -> Ubuntu/Debian: sudo apt install python3-tk python3-pil.imagetk

"BRAKUJE PLIKÓW" w konsoli
      -> zdjecie_plytki.png i lista_elementow.json muszą leżeć
         w tym samym folderze co testuj_plytke.py

"Stary plik wzorzec.json nie pasuje..."
      -> lista elementów się zmieniła (np. doszedł U1).
         Kliknij raz [★ Zapisz wzorzec], potem testuj.


---------------------------------------------------------
  UWAGA
---------------------------------------------------------

Domyślnie program uruchamia się w trybie DEMO (dane symulowane).
Gdy podepniesz prawdziwy tester z ESP32, niczego nie trzeba zmieniać
w kodzie — po prostu zmień [ŹRÓDŁO] na górze z DEMO na port COM.
